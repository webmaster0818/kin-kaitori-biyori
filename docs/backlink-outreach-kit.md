最終更新: 2026-07-09 ／ 目的: ドメイン権威（被リンク）を費用ゼロで積み上げる。相場データ・白書・ウィジェットを「引用元／データ提供元」として自然に被リンクを獲得する。

> ⚠️ **社外への実送信は必ずMediaXAIの承認を得てから**。本ファイルは打診の「素材」（誰に・何を・どう伝えるか）。一斉送信・スパムは厳禁（[[writing-standard-v2]]／各媒体の規約遵守）。1件ずつ相手の文脈に合わせてパーソナライズする。

## 2. ターゲットセグメント（誰に打診するか）

被リンクは「相手にとって本当に価値がある」ときだけ自然に付く。以下は金相場データ／ウィジェットが実際に役立つ層。

1. **金・貴金属・資産運用系の個人ブログ／メディア** … 金投資・純金積立・地金の解説記事に「本日の相場」ウィジェットは相性◎
2. **FP・士業（相続・税金）系ブログ** … 相続財産評価・貴金属の売却と税金の記事にデータ引用
3. **リサイクル／不用品処分／買取比較系サイト** … 「金の売り方」記事に相場データ・計算機を補助ツールとして
4. **地域情報メディア／まちの買取店紹介** … 地域の買取店記事に相場の目安として
5. **節約・ライフスタイル・主婦系ブログ** … 「使わないアクセサリーを売る」文脈で計算機・相場
6. **経済ニュース／相場まとめ系** … 相場推移チャート・白書の数値を出典付きで引用

**探し方（無料）**: Google検索 `金相場 ブログ` `純金積立 個人ブログ` `金 売却 税金 site:ameblo.jp` 等／`intitle:金買取 相互リンク`／既に他サイトの相場ウィジェットを貼っている個人ブログ（＝設置意欲がある層）を逆引き。

## 4. 進め方・ルール

- **承認フロー**: 送信先リストと文面をMediaXAIに共有 → 承認 → 送信（[[report-per-channel-no-conflation]]）。
- **1日の件数を絞る**（例: 5〜10件/日・手作業でパーソナライズ）。テンプレ一斉送信はスパム扱い＝逆効果。
- **返信・設置状況を記録**（このファイル末尾のログ表 or 別スプレッドシート）。
- **設置されたら**: そのページからの被リンクをGSC「リンク」レポートで確認。ウィジェット経由の流入は将来 `utm` 付きリンクで計測可。
- **禁止**: 有料リンク購入・リンクファーム・相手を欺く文面（Googleガイドライン違反＝ペナルティリスク）。
